## More detail

Agent Orchestrator is designed for teams that want autonomous coding agents to act with real context, constrained permissions, and visible accountability. The interface is built to make the state of a project legible: what is running, what was changed, what an agent was asked to do, and whether it passed the judge.

Use this page as a visual index of the app surfaces. For the full project overview, return to the [main README](../README.md).
